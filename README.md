# Corso di Formazione - Materiale di Studio ed Esercizi

Benvenuto/a in questo repository! In questa cartella sono raccolte tutte le risorse didattiche e gli esercizi svolti relativi al corso, suddivisi in modo chiaro ed ordinato per ciascuna lezione.

----

## 📁 Struttura del Repository

La cartella principale contiene **8 sottocartelle** (dalla Lezione 1 alla Lezione 8).  
All'interno di ogni singola sottocartella troverai:
* 📄 **Materiale delle lezioni**: slide, note teoriche, dispense e codice di esempio spiegato a lezione.
* 💻 **Esercizi svolti**: traccia degli esercizi assegnati e relative soluzioni pratiche o script di approfondimento.
